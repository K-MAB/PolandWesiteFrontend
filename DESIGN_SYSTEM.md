# Design System

The visual language combines a technical catalog with a clear specialist retail store. Navy, blue and cyan communicate reliability without hiding product data behind decorative effects.

- Inter Variable is the primary typeface.
- Navy is used for navigation and high-emphasis headings.
- Blue is the main action color; cyan is a restrained accent.
- Product cards prioritize image, exact MPN, stock, price and add-to-cart action.
- Storefront pages use comfortable density; admin tables use compact but accessible rows.
- The platform displays one final tax-free price with no tax field.
- Mobile collapses portal navigation and preserves horizontal scrolling only for data tables.
